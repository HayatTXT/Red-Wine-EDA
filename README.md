# Red Wine Quality EDA

## Overview
This project focuses on performing Exploratory Data Analysis (EDA) on the Red Wine Quality dataset using Python. The objective of the analysis is to understand the relationship between physicochemical properties of red wine and wine quality ratings.

The project includes data cleaning, statistical analysis, correlation analysis, and feature visualization to identify important factors affecting wine quality.

---

## Objectives
- Explore the distribution of wine quality ratings
- Analyze relationships between chemical properties and quality
- Identify highly correlated features
- Detect patterns and trends within the dataset
- Perform data cleaning and preprocessing

---

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## Analysis Performed

### Data Cleaning
- Checked missing values and duplicate records
- Removed duplicate observations
- Verified dataset consistency and data types

### Exploratory Data Analysis
- Univariate and bivariate feature analysis
- Correlation heatmap analysis
- Pairplot visualization for feature relationships
- Distribution analysis of numerical variables

### Feature Analysis
- Investigated relationships between alcohol content, acidity, sulphates, and wine quality
- Identified variables with strong positive and negative correlations
- Compared feature distributions across quality ratings

---

## Key Insights
- Alcohol content showed a positive relationship with wine quality ratings
- Volatile acidity negatively impacted wine quality
- Sulphates and citric acid demonstrated moderate correlation with higher-quality wines
- Several chemical properties exhibited multicollinearity patterns
